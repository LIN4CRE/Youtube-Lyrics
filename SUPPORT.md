# Getting help

1. Read the README's [troubleshooting section](README.md#if-something-is-off).
2. Check the app version and confirm that your player publishes a Windows media session. Some players do not.
3. If the issue is reproducible, open a [bug report](https://github.com/LIN4CRE/Youtube-Lyrics/issues/new?template=bug_report.yml) with Windows version, player, steps, and expected/actual behavior.

Logs are stored at `%LOCALAPPDATA%\YouTubeLyrics\ytlyrics.log`. They can contain track titles and artist names; review and redact them before sharing. Never post credentials, private track history, or copyrighted lyrics.
